# 한국 가요 마스터 챌린지

1980년대부터 2000년대까지의 한국 가요를 사진과 힌트로 맞히는 퀴즈 웹앱입니다. 한 번에 30문제가 나오며, 난이도에 따라 사진의 선명도와 점수가 달라집니다.

## 사용 방법

1. `index.html`을 웹 브라우저에서 엽니다.
2. 라이트, 클래식, 마스터 중 난이도를 고릅니다.
3. 노래 제목과 사진을 보고 가수 또는 그룹을 선택합니다.
4. 30문제를 모두 풀면 점수와 오답을 확인할 수 있습니다.

최고 점수는 사용 중인 브라우저 안에 저장됩니다. 사진을 보려면 인터넷 연결이 필요합니다.
